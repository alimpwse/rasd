# RASD — Field Notes

نسخة **0.16.0**، جاهزة للنشر على GitHub Pages. تطبيق لتوثيق ملاحظات مواقع المشاريع بالصور والفيديو، بواجهة إنجليزية تدعم الكتابة بالعربية.

**تحديث المستودع الحالي:** [دليل التحديث بالعربي](UPLOAD_TO_GITHUB.md). فك الحزمة وارفع ملفات التحديث إلى جذر مستودع RASD الحالي.

- [AGENTS.md](AGENTS.md): تعليمات وسياق لأي نموذج ذكاء اصطناعي سيعدل التطبيق.
- [docs/TECHNICAL.md](docs/TECHNICAL.md): تفاصيل الميزات والقيود والاختبارات.
- [VERIFY.md](VERIFY.md): الفحوص المنفذة وما يحتاج تجربة على الآيفون.
- `dist/`: التطبيق الكامل، وهو المصدر الفعلي الذي يُعدّل مباشرة.
- `tests/`: اختبارات المنطق والمتصفح.
- `.github/workflows/pages.yml`: نشر تلقائي لمجلد `dist` عند تحديث فرع `main`.

لا يحتاج التطبيق تثبيت مكتبات أو خطوة build للنشر. إعداد GitHub Pages المطلوب هو **Source → GitHub Actions**.

الصور والفيديو والملاحظات والإعدادات تبقى محلياً على جهاز كل مستخدم. هذه الحزمة تحتوي كود التطبيق فقط؛ لا تحتوي ملاحظاتك أو صورك أو نسختك الاحتياطية. عند الانتقال إلى نطاق جديد، احفظ مسوداتك، ثم استخدم **Back up everything** في النسخة القديمة و**Restore backup** في الجديدة قبل الاعتماد عليها.

## تحديث 0.16.0

يحاول التطبيق تحسين قراءة الموقع الضعيفة. تقدر تحفظ الملاحظة مباشرة، ويظهر الرابط التقريبي في المشاركة بعد تأكيد الدبوس أو تصحيحه من **GPS details**. الضغط المطوّل على زر التصوير يسجّل فيديو عند توفر المعاينة. إذا تعذّرت المعاينة، يفتح كاميرا الفيديو الأصلية عند رفع الإصبع.

## تحديث 0.15.0

الصور المعدلة تُشارك بصيغة JPEG بنفس عدد البكسلات ضمن الاقتصاص المختار. يبدأ الترميز بجودة 0.92 ويخفضها تدريجياً للصور الكبيرة. ملف الصورة الأصلي يبقى كما هو. الملاحظات متعددة المرفقات تجهّز ملفاتها عند المشاركة أو التصدير. تعرض Quick phrases كل المجموعات وتغيّر تصنيف الملاحظة حسب العبارة المختارة.

## الفيديو

اضغط زر التصوير ضغطة عادية للصورة، أو اضغط مطولاً لتسجيل فيديو بالصوت وارفع إصبعك للإيقاف. خيار **Record video with phone camera** و**Library** متاحان أيضاً. الفيديو يبقى كما هو، وترافقه الملاحظة ورابط الموقع عند المشاركة حسب إعداداتك. الحد دقيقة و50 MB لكل فيديو، و10 مرفقات / 100 MB للملاحظة. الرسم وشريط المعلومات يخصان الصور فقط؛ تقرير PDF يعرض معاينة ثابتة للفيديو.

التسجيل المباشر يعتمد على إمكانات Safari والصلاحيات؛ لا يضمن خصائص كاميرا Apple مثل HDR. أبقِ التطبيق ظاهراً أثناء التسجيل واحفظ الملاحظة قبل الخروج. النسخة الاحتياطية الكاملة حدها 64 MiB، لذلك قد لا تتسع لمكتبة فيها فيديوهات كبيرة.

## التشغيل المحلي للمطوّر

من داخل هذا المجلد، باستخدام Python 3:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

افتح `http://127.0.0.1:4173/`. على Windows يمكن استخدام `py -3` بدلاً من `python3`. فتح `index.html` مباشرة عبر `file://` لا يشغّل التطبيق بصورة صحيحة.

اختبارات المنطق تحتاج Node.js 24 أو إصداراً أحدث متوافقاً:

```sh
npm test
```

اختبارات المتصفح وإجراءات إصدار التحديثات موضّحة في [AGENTS.md](AGENTS.md). المستخدم الذي سيرفع الملفات فقط لا يحتاج Python أو Node أو npm.

## الملفات المرخّصة

خط IBM Plex Sans Arabic مضمن محلياً مع رخصة SIL OFL في `dist/fonts/OFL.txt`. احتفظ بالرخصة عند نقل الخط أو توزيعه. لم تُضف رخصة مفتوحة المصدر لكود التطبيق؛ نشر المستودع كـ Public لا يختار رخصة نيابة عن مالكه.
